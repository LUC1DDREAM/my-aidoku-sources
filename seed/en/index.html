Setup

iPhone & iPad

  1. Install Aidoku

    Get the app from the official Aidoku website. If you already have it, keep a backup of your library.

    aidoku.app ↗

  2. Add the list

    Open this page on your iPhone or iPad, tap “Add to Aidoku” and confirm the list in the app. If it does not open, copy the list URL and add it manually in Aidoku.

  3. Choose your sources

    In Aidoku, enable English and Multilingual in the source language filter, then install the sources you want. The website language does not change the source language.

Manual list URL

https://luc1ddream.github.io/my-aidoku-sources/experimental/index.min.json
